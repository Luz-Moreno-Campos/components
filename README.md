# Go Wild Travel - *Your Next Adventure Starts Here*

Go Wild Travel is a premium adventure‑travel company dedicated to connecting travelers with extraordinary outdoor experiences across the globe. 

## 🌐 Company Overview

Go Wild Travel specializes in immersive, nature‑driven travel experiences designed for explorers seeking authenticity, challenge, and unforgettable moments.  
Our mission is simple: **to inspire people to reconnect with the natural world through meaningful adventure.**


## 🛠️ Technology & Architecture

The site was built using **React**, following a modular component‑based architecture to ensure scalability, maintainability, and clarity.

##  ✨Key Features

- **Header**  
  Corporate navigation bar featuring the Go Wild Travel brand and main menu.

- **Banner**  
  Hero section introducing the company’s message with strong visual impact and clear calls to action.

- **Reusable Button Component**  
  Supports primary and secondary styles for consistent branding.

- **Gallery**  
  A selection of four adventure images, dynamically rendered using `.map()`.

- **Footer**  
  Includes brand messaging, social media presence, and corporate identity elements.
